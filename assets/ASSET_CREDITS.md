# Asset credits

The files under `island/` and `audio/` were created specifically for this SustainableIsland project. No external asset packs, stock images, fonts, or paid assets are needed for the new game. You may use, edit and redistribute these new assets with your project.

## Included vector art

`island_map.svg`: coastline, paths, forest, mangroves, pier and reef details.
`guesthouse.svg`, `hotel.svg`, `market.svg`, `culture.svg`: tourism facilities.
`waste.svg`, `utilities.svg`: recycling and clean-resource infrastructure.
`forest.svg`, `reef.svg`: conservation locations.
`boat.svg`: animated sailboat.
`leaf.svg`: application icon and interface emblem.
`marker.svg`: spare placement marker for future extensions.

The SVG files are original code-authored artwork and can be edited in a vector editor. The game uses Godot's built-in font.

## Audio

`click.wav`, `day.wav`, `success.wav`: original synthesized tones, mono PCM WAV, 22,050 Hz.

## Existing assets

`bg1.webp` and `Title.png` were supplied in the original project and retained for the account screens. Their original provenance/licensing was not provided; this package does not change their ownership or usage terms.
